# Feature Specification: ツールバーアイコンのフォント問題修正

**Feature Branch**: `002-fix-toolbar-icons`
**Created**: 2025-12-10
**Status**: Draft
**Input**: 音価と休符モードのフォントが潰れて豆腐になっている問題を修正

## User Scenarios & Testing

### User Story 1 - 音符アイコンの正常表示 (Priority: P1)

ユーザーがツールバーの音価ボタン（全音符、2分音符、4分音符、8分音符、16分音符）を見たとき、それぞれの音符が正しいアイコンとして表示される。

**Why this priority**: 音符入力はアプリの主要機能であり、ユーザーが音価を識別できないとアプリが使用不能になる。

**Independent Test**: アプリを起動し、ツールバーの音価ボタンが□（豆腐）ではなく音符アイコンとして表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** アプリが起動している, **When** ツールバーを見る, **Then** 全音符アイコンが白抜き楕円として表示される
2. **Given** アプリが起動している, **When** ツールバーを見る, **Then** 2分音符アイコンが白抜き楕円と符幹として表示される
3. **Given** アプリが起動している, **When** ツールバーを見る, **Then** 4分音符アイコンが黒塗り楕円と符幹として表示される
4. **Given** アプリが起動している, **When** ツールバーを見る, **Then** 8分音符アイコンが黒塗り楕円、符幹、旗1本として表示される
5. **Given** アプリが起動している, **When** ツールバーを見る, **Then** 16分音符アイコンが黒塗り楕円、符幹、旗2本として表示される

---

### User Story 2 - 休符アイコンの正常表示 (Priority: P1)

ユーザーがツールバーの休符モードボタンを見たとき、休符記号が正しいアイコンとして表示される。

**Why this priority**: 休符入力も基本機能であり、P1と同等の重要性を持つ。

**Independent Test**: アプリを起動し、休符モードボタンが□（豆腐）ではなく休符アイコンとして表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** アプリが起動している, **When** ツールバーを見る, **Then** 休符モードボタンに休符アイコンが表示される

---

### User Story 3 - アイコンのインタラクション維持 (Priority: P2)

SVGアイコンに置き換えた後も、ボタンのクリック、ホバー、選択状態のスタイルが正しく動作する。

**Why this priority**: 機能の維持は重要だが、表示が修正された後の検証事項。

**Independent Test**: 各ボタンをクリックして選択状態になること、ホバー時にスタイルが変わることを確認する。

**Acceptance Scenarios**:

1. **Given** アプリが起動している, **When** 音価ボタンをクリックする, **Then** ボタンが選択状態（アクティブスタイル）になる
2. **Given** アプリが起動している, **When** 休符モードボタンをクリックする, **Then** ボタンがトグル状態になる

---

### Edge Cases

- アイコンが小さいボタンに収まるか？
- ダークモード対応が必要か？（現在はダークモードなし）
- 高DPIディスプレイでアイコンがぼやけないか？

## Requirements

### Functional Requirements

- **FR-001**: システムは全音符、2分音符、4分音符、8分音符、16分音符をSVGアイコンで表示すること
- **FR-002**: システムは休符モードをSVGアイコンで表示すること
- **FR-003**: SVGアイコンはボタンサイズ（約36x36px）に適切にフィットすること
- **FR-004**: アイコンは currentColor を使用して、ボタンの状態（通常、ホバー、アクティブ）に応じた色で表示されること
- **FR-005**: アイコンは高DPIディスプレイでも鮮明に表示されること（ベクターグラフィックスの利点）

### Key Entities

- **NoteIcon**: 音符を表すSVGコンポーネント（size props対応）
- **RestIcon**: 休符を表すSVGコンポーネント

## Success Criteria

### Measurable Outcomes

- **SC-001**: すべての音価ボタン（5種類）が□（豆腐）ではなく認識可能な音符アイコンとして表示される
- **SC-002**: 休符モードボタンが□（豆腐）ではなく認識可能な休符アイコンとして表示される
- **SC-003**: 既存のE2Eテストがすべてパスする（リグレッションなし）
- **SC-004**: macOS、Windows、Linuxの各プラットフォームでアイコンが正しく表示される
